# Conditional advice after the fixed genuine variance pilot

Prepared from the binding specification, existing source and declared constraints. This is design advice, not execution authorization or final pilot adjudication. The fixed 16-teacher/R2 worker must finish unchanged. I did not read live/raw pilot data, import the package, run numerical work or tests, or change source/Git state. First-eight results in the brief are interim and do not determine the final branch.

The smallest justified next step is to audit the completed sealed pilot and list every actual blocking gate. If endpoint Monte Carlo error remains unresolved, a bounded, separately recorded resampling refinement on saved observations can distinguish numerical imprecision from sampling uncertainty. It cannot itself make this sealed pilot eligible under the existing publication contract. If substantial SD uncertainty remains, the honest current result is an inconclusive calibration pilot; further independent teacher evidence requires a prospective new decision and provenance, or the project proceeds to WP09 with that limitation.

Calibration acceptance is an outer gate. `calibration_status` requires independent teachers/repetitions, no failed pairs, two completed runtime batches stable within 20%, SD-interval ratio at most 2 when SD is positive, and endpoint error within the actual threshold `5.102856799298169e-05`. `choose_design` selects `calibrate` before considering unresolved intrinsic variance or either planning-effect interval. The static-control interval cannot bypass a failed SD or endpoint gate, and neither its sign nor H1's sign authorizes stopping. A missing/degenerate SD has a special source path into estimation after other checks; that is not evidence of equivalence.

Saved-data resampling changes computational precision only. The current diagnostic takes the maximum estimated endpoint SE across H1, static-control, SD and variance-component endpoints using ten disjoint bootstrap chunks. Refinement must preserve that diagnostic and its declared tolerance; refining only the favorable endpoint would answer a different question. More draws can stabilize the SD-ratio and variance-bound estimates if their numerical uncertainty matters, but cannot supply unseen teachers, repair model/coverage assumptions, resolve tails absent from the sample, or guarantee a positive intrinsic-variance lower bound. A prespecified bounded precision-based refinement is scientifically distinct from searching seeds or draw counts for favorable signs or eligibility. Its cost should be measured before calling it inexpensive in practice; it avoids training, but saved-data loading still has memory/time costs.

New teachers address independent population sampling. New optimizer repetitions address within-teacher noise and remain repetitions, not additional teachers. Under the crossed design, shared E-row noise does not generally shrink as 1/R; increasing repetitions is therefore not a substitute for teacher or evaluation-row evidence. The source explicitly keeps completed R and requires new variance/cost calibration for a changed R. With unresolved intrinsic variance, its cost optimum may itself be undefined. Additional evaluation rows would be new observation evidence and a changed recipe, not saved-data MC refinement. None of these changes is authorized for the active worker.

The provenance barrier is concrete. `eligible_design` verifies the raw seal, current source digest, readiness and constraints, recipe hashes in every pair, retained predictions, counts and doubling sequence. It recomputes the summary using **raw config** bootstrap iterations/seed and the decision using **raw constraints**. The configured maximum is 16; policies bind 8,000 bootstrap draws to that recipe. `publish_design`, `load_design` and `freeze` all reconstruct eligibility instead of trusting a hand-filled result. Editing a summary alone cannot change eligibility; changing config/constraints or raw data in place breaks the evidence bindings. A supplemental analysis must carry its own date, source/analysis identity, raw input hashes, parameters, outputs and relationship to the original record. Public reporting must show both the original failed gate and any supplemental findings. No protocol hash should be overwritten or unsupported freeze implied.

A fresh independent estimation study is scientifically possible even when the current pilot does not pass strict calibration, but it is **not an already authorized or currently eligible WP06 route**. The specification allows estimation/resource-limited scope; its normal estimation route still presupposes accepted calibration in this implementation. Proceeding outside that gate requires an explicit prospective amendment/new study design acknowledging the unresolved calibration, fixing estimand, independent namespaces, counts, finite evaluation size, all analysis/retry/stopping policies, resource limits and claim restrictions before new outcomes. Independence alone does not validate the interval method. This advice supplies neither that amendment nor a mechanism for bypassing protected T access. Without an accepted amended route, the honest deliverable is the diagnostic/inconclusive pilot plus WP09, not a nominally frozen estimation cohort.

The recorded cap is justified by measured sample extrapolation and chosen allowances (pilot 14,400 seconds, confirmation 28,800 seconds), with explicit storage/memory reserves. It is not a proof that additional scientifically useful work is impossible. Root should therefore assess actual completed costs and the remaining question before concluding that only reporting remains, while preserving all current caps and worker instructions. Any extension requires a fresh prospective decision rather than a favorable-sign exception. Sleep-delayed UTC duration and measured execution time must remain separate; neither should be silently substituted for the resource evidence.

If further evidence is not justified or supported, WP09 still delivers scientific value: preserve every attempt and control, reconstruct metrics, audit resources/provenance, demonstrate the required representative reproduction/resume behavior, regenerate reports and state exactly which H1 inference remains unresolved. A crossing exploratory interval is inconclusive; an SD gate failure is calibration uncertainty; a zero variance lower bound is unresolved decomposition. None supports equivalence, practical uselessness, or absence of an effect. No application utility/equivalence margin exists here.
