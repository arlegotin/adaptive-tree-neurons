# Owned secondary search episodes

A distinct strict secondary program-request schema includes the actual global
barrier, native qualification, resource forecast, plan, support and procedure.
The caller derives the duplicate pins from the real frozen payload. The worker
reloads the actual global/native gates and checks those pins before staging data.
Primary request schemas reject an added secondary barrier; changing a fold or
flag cannot grant secondary access.

The common cold entry point keeps standard-library-only imports before its
ready/grant handshake. Secondary requests have a distinct worker identity and
body schema. The existing generic caller/cost record format retains its historical
names; the typed request/body/global binding defines the actual tranche. Complete
caller/process/journal histories and prior official samplers are checked on
resume. New preparation and losing attempts remain paid. Unknown authorized
failures are not converted into a free rerun.

Resource advice is applied before spawning and before each proposal. Live
shortages pause the same immutable job. Native stopping, fixed P06 sampler seeds,
model configuration, F/G/V roles and owned RSS/checkpoint-space guards remain
intact. No T or complete-study cost authority is provided.

The final affected eight-module suite passed **122 checks in 16.03 seconds**.
Tests cover strict metadata, import isolation, changed global pins, a real owned
cold rejection before data/output, RAM pause/recovery advice and existing primary
caller/program/search behavior. Complete-qualified public positive execution,
secondary trained-episode recovery and the serial672 program remain unrun or
unfinished; no successful complete registry/global barrier is fabricated.

The [receipt](WP09-secondary-episode-receipt.json) retains initial failures. New
pin tests exposed calling an object-only canonical JSON helper on hash strings;
a separate regression exposed the same mistake on an absent native component
in a resource-failure companion. Wrapping these values in objects fixed both
boundaries before production. Historical data/results and the live held native
study were unaffected. Earlier scoped passes did not cover these two cases.

The serial secondary queue, complete840 retained-model/protected barrier,
evaluator/raw audit, physical costs/deployment, production CLI/readiness and
final review still precede final-source qualification and production searches.
