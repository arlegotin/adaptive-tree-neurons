# Native anchor execution evidence

`research.native_anchor_v2.qualify_native_anchor` joins the matching fixed
software-verification profile with an exact declared native anchor, its managed
source/data/state chain, fresh closed-model prediction replay and primary V
arithmetic. Qualification uses seed17 and the original fixed anchor inventory.
A valid search-only configuration cannot masquerade as a required native anchor.

The software proof must match the current source/test/helper/lock identity.
Wrong software, seed or anchor configuration rejects before new V access or
output creation. A successful inspection must agree with its published packet;
the implementation proof/source is checked again afterward. Outputs must stay
outside the original generation, prepared store and executable inputs. Original
generation bytes remain unchanged. An owned replay memory stop retains its
failure and cannot produce a qualified execution or new V-label read. F/G
authentication may still append its legitimate recorded accesses.

Only `native_anchor_execution_authenticated` and its software/replay facts become
true. Raw acquisition, complete variable-workload/support bounds, production
quality, HPO journal and protected authority remain false. The future registry
must add the real data and complete scope evidence before admitting a method.
The V value is retained for audit and is never used as a technical inclusion
threshold. An unfavorable baseline remains a required comparison.

Six missing-interface failures preceded six passing new cases in25.98seconds.
The final32-case affected suite passed75.49seconds, including software checks,
native generation and replay regressions. The positive case uses actual native
P13 fitting and its real source-bound software check on synthetic sealed Energy
roles; it supplies no official acquisition or real-data native-anchor count.
The nonanchor regression uses a genuine allowed P13 ridge configuration. See
[the source/log receipt](WP07-native-anchor-execution-receipt.json).

The containing elapsed time includes software validation and inspection; the
inspection span is nested. The caller retains complete publication/return and
earlier fitting/software-qualification costs. This packet makes no complete
whole-process cost or predictive-efficacy claim.

`load_native_anchor_execution(reference, prepared_root=..., ...)` now reopens
this proof for a named dataset/family/anchor. The caller supplies externally
committed closed artifact and prepared-manifest hashes. The reader checks the
current software proof, exact native configuration/seed, original managed
generation and immutable container, independent replay process/terminal, and
the original-versus-replayed snapshot/query/prediction bindings. JSON decoding
uses the bytes committed by the artifact inventory. Source and original files
are checked again before returning.

The reader runs as the **primary V coordinator**: after nonlabel provenance
checks pass, it independently recomputes primary validation arithmetic through
the logged access boundary. It does not fit or rerun inference, and it never
opens protected T. Rechecking V does not select a configuration or determine
technical inclusion. A raw-acquisition/support/workload registry is still
required; the returned workload/quality/protected flags remain false.
