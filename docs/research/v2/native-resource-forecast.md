# Native practical resource forecast

`forecast_native_practical_resources` requires the actual complete native
qualification registry before reading the plan, support lock or proof files.
It binds the existing 840-job native-quality program and its 168 primary jobs,
then collects native anchor durations, anchor/support sampled RSS, and retained
logical file sizes. External model-generation directories are included;
overlapping files are counted once within a measured procedure footprint.
The function writes nothing and starts no model process.

For each dataset/family, the runtime projection uses the largest observed
native anchor duration times the 32 paid-attempt cap. Short support probes
contribute memory/storage measurements and do not predict convergence time.
This is a heuristic projection, not a P50/P90 estimate, upper bound or deadline.
Registry verification, planning and final containing costs remain additional
measured costs. Secondary-fold projections do not qualify those workloads.

The full program retains 26,880 maximum paid slots, including failures/retries;
the primary tranche has 5,376. P13's finite space has 29 configurations, so a
no-retry traversal has 26,700 configurations overall and 5,340 primary ones.
These counts are distinct and do not reduce the actual 32-attempt ceiling.

Live advisory admission reserves twice the largest measured procedure footprint
plus 64 MiB for a transaction, one further footprint for independent recovery,
and at least 1 GiB of free-space margin. Its RAM proxy is 1.25 times the largest
sampled anchor/support root RSS plus 512 MiB. These disclosed proxies cannot
guarantee unseen configurations or aggregate memory. The existing worker RSS
guards and exact NODE checkpoint transaction check remain necessary. RAM
unknown/shortage and disk shortage deny admission without changing the pending
configuration, data, seed or native stopping rule. There is no elapsed-hour
cutoff or fixed 20 GiB free-RAM requirement. Host observation uses disk space
and a system RAM proxy; it does not enumerate other processes.

The affected four-module suite passed **85 checks in 3.48 seconds**, including
exact counts, finite-support/retry distinctions, native versus short-probe
timing, storage outside qualification directories, stale/incomplete inputs,
live shortages and secondary-release denial. Pure reducers and decision
fixtures explicitly grant no qualification or execution authority. Their
synthetic resource values are not an observed forecast for this computer.
Full public execution with genuine current-source qualification remains unrun.

The [receipt](WP08-native-resource-forecast-receipt.json) retains source and test
evidence. Production launcher/per-candidate admission integration, whole outer
cost and final protocol remain unfinished. Existing completed experiments and
the active held-source NODE sequence are unchanged.
