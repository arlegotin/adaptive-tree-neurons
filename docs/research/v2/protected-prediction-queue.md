# Protected prediction queue component

The public entry loads the actual final practical protocol before any study
output. That loader still requires genuine complete model/native/global,
pre-T cost and production-readiness evidence. Callers cannot supply an
authenticated context or replace those gates with a true flag.

One invocation holds a private immutable copy of that genuinely loaded
protocol. Full gates run around the queue; each query retains exact source,
protocol, owner, journal, saved-model and feature bindings. This is an
in-invocation context, not a persistent qualification cache or migration.

The queue uses the frozen query order, reserves the witnessed query before
feature access and runs the owned cold leaf. It commits only independently
checked process/body/numerical evidence. Resumption reuses valid committed
predictions; it does not predict them again. Resource denial resumes the same
frozen query. Dependency failure receives at most one same-seed rerun.
Ambiguous active state, terminal failure and changed evidence block progress.

All successful and failed attempts now reconcile their paid duration with the
actual full executor call and containing owned-process bounds. The new strict
query_failed_with_evidence event commits a failure's evidence hash. Legacy
unqualified metadata failures remain readable by the metadata helper but cannot
supply actual queue accounting. This is a pre-production schema-kind extension,
not a migration of an old scientific study.

A final context failure prevents the all-predictions barrier even when two
fixture outputs have already been saved. The queue never opens test labels.
The barrier and metadata flags alone cannot authorize a later label read.
