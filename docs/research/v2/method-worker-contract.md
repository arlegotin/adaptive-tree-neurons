# Fresh method-worker engineering boundary

Task7/8 needs a common process entry point before complete native workloads can
be measured under the existing own-process supervisor. This slice is engineering
only: it cannot grant quality eligibility, admit HPO or release protected data.

A trusted request digest commits a strict JSON request, the exact scientific
Python source digest, family/configuration, fixed32-bit fit seed, observation
identity and hashed F/G/V-feature NPZ inputs. F and G contain labels; the query
file must contain features and row/group IDs only. Validate the request identity
and observation inputs before importing a method adapter; the selected adapter
then validates its native configuration and dependencies. Reject unknown roles/fields, object arrays, duplicate
or overlapping row IDs, cross-role groups, escaped file paths, changed bytes,
nonfinite data, invalid shapes or a changed source identity. Do not truncate rows
or encode categories before the declared native F-fitted transform.
Temporal requests retain actual timestamps, require increasing rows and a minimum
24-clock-hour gap between successive F/G/V roles. They do not fill missing hours.

Dispatch a fixed allowlist to the versioned lazy native adapters. Native
workload qualification remains separate from registration. No fallback
model, generic import from request text, seed replacement or eligibility promotion.
Use each adapter's FitRequest, original-unit prediction and closed snapshot APIs.
Save predictions with their original row/group IDs and verify same-process snapshot
reload. Retain adapter resources, complete file commitments, errors and body time.
The enclosing supervisor owns process startup, deadline/RSS outcomes and final
whole-process time; a worker exit code alone establishes no predictive eligibility.

Fixtures must prove pre-import refusal of forbidden labels/source/file changes,
role and row correspondence, native closed-form execution/reload without importing
Torch/NODE, terminal failure retention and no overwrite. Native neural/tree
workloads and supervisor integration receive their own measured qualification.
All labels here are synthetic fixtures; no prepared transfer or T access occurs.

The full practical program and all downstream source must still be ready before
production searches/calibration. This bridge is a prerequisite, not GateD or a
claim that the840-job program has run.
