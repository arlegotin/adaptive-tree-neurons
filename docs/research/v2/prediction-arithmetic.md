# Independent prediction arithmetic

`analysis.prediction_arithmetic_v2.audit_prediction_arrays` recomputes metrics
from already authorized original-unit target and prediction arrays. It opens no
data or model files, invokes no predictor and uses no producer metric helper.
Frozen source/data/model/access authentication belongs to the eventual sealed
reader; this numerical component grants no protected access or claim authority.

F target variance uses ddof0. Synthetic row grouping requires group IDs to equal
row IDs. Grouped transfer permits repeated group IDs and averages groups equally,
then rows within groups. Temporal scoring requires strictly increasing actual
timestamps and matching calendar-day IDs; missing hours remain gaps. Both primary
weighted metrics and ordinary row-weighted MSE/RMSE/MAE are retained.

Each method supplies exact evaluation row identities. Reordering, duplicates,
nonfinite predictions, undeclared methods and scoring failed methods fail. The
complete planned status inventory is retained; missing/failed predictions produce
an incomplete result without risk imputation. Constant F targets retain raw-unit
metrics with undefined normalized risk. Unrepresentable losses fail. A stable
sum preserves representable subnormal errors and finite means whose unscaled
sum overflows.

Hand-calculated sentinel vectors distinguish row MSE5/3 from equal-group MSE1.5
and verify a second method's equal-group MSE.25. Eleven missing-component checks
became eleven passing checks; a further subnormal-loss regression failed and was
corrected.101 affected arithmetic/teacher/practical/design/cost checks then passed.
This is software and arithmetic evidence, with no real models, calibration,
transfer evaluation or production T access. The metadata schema is a component
record under confirmation/v2; complete protected records, frozen readers,
independent artifact audit, deployment workers and canonical final reporting
remain pending.
