# Secondary development data after the global barrier

`ReleasedTransferStore` reloads the actual global barrier before inspecting any
dataset, prepared manifest, array or access log. It selects the prepared root
from the source-validated global payload and checks its frozen manifest identity.
A caller-written flag or constructed barrier object cannot replace that loader.
Actual complete-qualified public release remains unrun.

This is a separate API; legacy `TransferStore` still rejects secondary folds.
The released training view contains F/G observations and V features/row IDs.
V labels remain with a separate coordinator method. Both view properties and
label methods continue to deny T. Secondary native-workload qualification and
the later full protected evaluator remain separate requirements.

New secondary events use a locked hash-chain journal under
`artifacts/research-v2/released-access/<plan-hash>/<dataset>.jsonl`, bound to the
actual barrier/source/manifest/split and actor. They never enter the legacy
primary log or add mutable files to qualified prepared-data/proof inventories.
Changed protocol identity, corrupt history, primary folds, undeclared actors
and T roles are rejected. This records API behavior, not unlogged filesystem
nonaccess.

The affected five-module suite passed **59 checks in 0.59 seconds**. Five initial
missing-module failures preceded implementation. Two further failures exposed
reading an append-mode journal from its end, bypassing its existing history;
seeking to its start under the lock fixed that issue. The
[receipt](WP09-released-transfer-receipt.json) retains the failures and final
source. Positive data tests use an explicitly unqualified toy Energy-shaped
table; public negative tests reject false qualification before data/log access.
No real transfer labels, native fits or T were used.

The private data engine preserves sealed row/group IDs, optional dates, feature
names and legacy stream identities without refitting preprocessing. Its test
views grant no native/model qualification. The actual secondary native adapter,
workload and search routes, full post-secondary model/T barrier, evaluator/auditor,
physical costs, production CLI/readiness and final review remain unfinished
before final-source qualification and primary production.
