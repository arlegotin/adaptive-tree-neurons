# Owned primary caller

`run_primary_search_episode` captures its clock before qualified preflight,
requires the resource-bound procedure and creates nothing until the actual
registry, plan, support, split, resource cache and output locations pass.
Request bytes are published with their exact hash under a fresh episode root.
The caller uses the prepared interpreter-preserving command and core-only
environment. It runs one episode, with no automatic retry or training deadline.

The owned cooperative observer checks live resources before starting the worker.
Denial closes a measured no-child episode. If resources permit a start, it
checks again after the worker is ready and before granting permission to fit.
The existing per-trial host checks remain inside the worker. Previously absent
pre-spawn checks stay disabled in the generic observer's default contract.
Denials require consistent raw decisions, start policy and disposition.

Never-authorized roots receive immutable references usable by the existing
unstarted-cost reader. Authorized failures and missing primary outcomes are
kept separate and receive no unstarted retry reference. A closed primary body
keeps its body/result references; actual native journal/model qualification
still belongs to the independent audit and model barrier. Engineering/generic
caller outcomes grant no native quality or protected-data authority.

The containing root clock includes parent preflight, request publication,
startup, worker activity, reap and log hashing. The caller also retains its
additional interval through observer return and metadata readback. Its own
final outcome publication is outside that endpoint. A later
[completion boundary](caller-cost-boundary.md) includes that publication and
routes the known caller interval into future search prefixes. Root and caller
intervals are nested and must not be added twice. Covering the completion
record's own publication/return with the physical study clock remains required
before a complete cost claim. No missing or unmeasured interval is assigned zero.

The affected six-module suite passed **123 checks in 7.85 seconds**. Five real
generic caller episodes cover success, pre-spawn denial, changed resources
before grant, authorized failure and a missing required primary body. Two
direct pre-spawn checks additionally forbid process creation on known denial
and show an exact primary command can retain an unstarted cost without spawning.
They fit no native models. Tests first exposed missing APIs, then four clock/
decision-consistency regressions before their fixes. The
[receipt](WP08-primary-caller-receipt.json) retains commands and source evidence.

Full actual-qualified public success remains **unrun**. It was not replaced by
a fake registry. Production queue/readiness, complete outer-cost audit, global
procedure freeze, secondary release and protected evaluation remain unfinished.
No existing scientific result or held-source job changes.

The optional [program-request binding](procedure-worker-binding.md) now carries
the exact practical semantic declaration through this caller and preflight.
It creates a separate strict subtype requiring measured resources as well.
The future production queue must require that subtype; this component alone
