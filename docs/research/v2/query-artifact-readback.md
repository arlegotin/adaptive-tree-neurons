The read-only checker reopens the saved terminal, feature query, selected model
metadata, complete snapshot inventory and prediction archive. It verifies the
source/protocol/request identities, declared thread treatment, finite prediction
dtype/shape and exact row, group and timestamp alignment. Unknown fields,
changed byte commitments and invented authority flags fail.

It rejects label filenames before opening their bytes, and accepts only the
explicit prediction/identity archive fields. It does not fit, reload or predict
a model again. Numerical readback grants no training-generation, owned-process,
protected-protocol or access authority. The actual coordinator must join those
separate proofs before committing a prediction to the journal.
