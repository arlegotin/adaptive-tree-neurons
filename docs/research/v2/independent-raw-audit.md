# Independent raw metric reconstruction

The public auditor requires the actual frozen analysis, protocol, complete
prediction stage and witnessed scoring completion before target or output I/O.
It verifies that analysis and scoring use the same metric inputs. Actual
complete-qualified public success remains unrun.

The preproduction policy now explicitly permits a fixed auditor to reread the
same sealed F/T targets after once-only scoring, solely for verification. This
implements WP11's independent recomputation requirement. It grants no model
update, configuration selection, refit or reset of the test study. No production
protocol or search had run when this clause was added. The final source and
policy must still be qualified and frozen before production.

The independent implementation uses NumPy reductions for original-unit errors,
F variance with ddof0, equal-group/day primary metrics, row metrics and normalized
group loss vectors. It does not call either producer arithmetic function. It
checks exact target/prediction row and hash identities, preserves undefined
normalization and compares every fixed query/metric against the scorer using
the fixed absolute/relative1e-12 tolerance. It never fits, loads or predicts a
model. Missing hours remain gaps.

Each reread records an explicit auditor access intent and closed outcome.
Fresh outputs preserve data, models, study/owner history, source and runtime;
the public guard additionally preserves native execution proofs. Failed audits
retain their terminal error and observed duration. Final publication, return,
containing caller and all prior attempts still require complete cost evidence;
this component grants no whole-pipeline cost or quality claim.

The software fixtures compare separately computed arithmetic and deliberately
inject a wrong producer score while retaining valid file commits. That case
tests whether the auditor detects a computational error; it is not a newly
observed research bug. Known local P13 targets are not benchmark test evidence.
