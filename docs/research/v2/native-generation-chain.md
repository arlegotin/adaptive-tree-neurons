# Native model generation lineage

`research.native_generation_v2.audit_native_generation` checks a closed native
attempt against the expected configuration, model seed and primary sealed data.
It reads no V/T labels and starts no fitting or model replay.

Supply the exact request byte hash, the native supervisor's externally committed
inventory reference, the prepared manifest byte hash and primary fold, and the
expected compiled configuration/fit seed. The verifier requires the current
scientific package identity. It does not silently accept an older package.

It checks the managed worker command, current interpreter binary path, source/overlay
and thread environment, successful reaped process, worker/file commitments,
closed snapshot pointer and producer's exact reload. F/G and V-feature hashes
must match the prepared primary roles; prediction rows/groups/timestamps must
match those V features. Explicit native stopping is required. Short engineering
neural/NODE configurations and failed/capped attempts cannot supply this proof.

The result authenticates the source-bound receipt and byte chain. It does not
independently reexecute optimization or predictions, authenticate original raw
acquisition, qualify the native recipe/workload/support, verify the HPO journal,
score V, select a winner or grant protected access. Those remain separate
production prerequisites. Existing engineering results are not retroactively
promoted. The expected compiled configuration must itself come from the frozen
support/proposal lineage; this checker does not choose or invent that support.

The immutable primary-selection inventory remains an integrity component, with
its native/model-generation/journal/V authority flags false. A future qualified
production assembly must compose the generation chain with native qualification,
the proposal journal, independent replay/validation arithmetic, resource policy
and the global freeze barrier. There is no production HPO or T access here.
