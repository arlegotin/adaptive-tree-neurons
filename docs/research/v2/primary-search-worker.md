# Cold primary-search worker body

`primary_search_worker_v2` joins the cooperative ownership handshake before
heavy imports. Its strict, hash-bound request contains metadata references,
the exact primary job, search directory and prior closed episodes. It rejects
unknown fields, ambiguous JSON, changed hashes and invalid paths or guards.
It receives no direct role arrays or extra label paths.

The worker requires the actual complete native qualification registry before
opening the practical plan or staging inputs. The existing global job compiler,
support lock, native factory and qualified callback then determine its procedure.
For RealMLP, the first episode creates the official native sampler inside the
paid clock using the job's 63-bit HPO namespace and actual qualified anchor
runtime. A clean resume reuses that immutable sampler. Native search keeps its
finite attempt limit and no wall cap; time-budget prefixes remain descriptive.

Controller entry uses the granted root's observed monotonic origin, including
startup, registry checks, sampler generation and preparation. A resumed body
pays the previous closed outer episodes' closing remainder before another
candidate can enter a prefix. Prior episodes must match the actual module
command, core-only environment, request, source/job, ownership, immutable result
and exact closed journal prefix. Later sessions append to that journal without
invalidating the retained earlier prefix. The full actual qualified search
auditor must validate the last endpoint before continuation. Costs are never
rolled back with a model's G-best checkpoint.

An interruption outside managed fitting can leave an unclosed search. The body
records the failure without manufacturing a closed candidate, assigning zero
cost or changing seeds. Such an episode cannot use the clean-resume path.
Native supervisors retain their existing nested cleanup and checkpoint rules.

The affected five-module suite passed **132 checks in 14.45 seconds**. Four
actual cold-process fixture episodes cover generic controller execution, a
two-episode pause/resume and the public worker's rejection of false qualification
before plan/data/output access. Read-only inspection reopens those episodes
without process creation. The controller fixtures use constant software scores;
they fit no native models and provide no predictive result. Complete public
qualified execution and its full native resume path remain **unrun**; no genuine
registry success was replaced with a stub or hand-written flag.

The [receipt](WP08-primary-search-worker-receipt.json) retains commands, source,
tests and initial failures. This worker is an implementation building block.
It does not supply measured whole-program resource admission, a production
queue command, the all-168-model capability, global procedure freeze or protected
access. The future launcher must validate its own control-output location before
creating handshake files and enforce the measured forecast and final-code
readiness. Body/factory guards protect working/proof/executable roots after
actual registry loading. The root clock still excludes its own final receipt
publication and unmeasured caller work; full procedure cost authority remains
false until the complete launcher and audit reconcile those boundaries.
