# Resource advice for released secondary jobs

The public secondary resource route first reloads the actual global barrier,
then binds the exact secondary job, forecast, source and support. Legacy primary
resource advice still refuses secondary jobs. Shared private arithmetic grants
no qualification, execution or protected-data capability.

The existing sampled memory and disk reserve proxies are unchanged. Low or
unknown RAM and low disk return a pause recommendation, preserving job/seed/state.
There is no blanket 20 GiB free-RAM requirement and no wall-time cutoff. A good
resource estimate does not qualify an unseen secondary workload or guarantee
that it will fit: owned RSS supervision, checkpoint transaction checks and the
new workload's actual native evidence remain required.

The affected four-module run passed **43 checks in 3.66 seconds**. The initial
six missing-module failures and a subsequent test-command filename error are
retained in the [receipt](WP09-secondary-resource-receipt.json). Positive fixtures
use artificial resource observations, including an admitted 2 GiB case for a
small synthetic envelope; that is not a claim that every real model fits in
2 GiB. Public false qualification fails before forecast access. No model, real
resource measurement, real transfer label or T was used.

The owned secondary worker/program still needs this advice wired into its
pre-spawn and per-proposal checks. Actual complete-qualified public execution,
full840/model/T evaluation, physical costs and final production readiness remain
unrun or unfinished; this component changes no scientific conclusion.
