# Freeze primary models before secondary development

`seal_global_primary_barrier` and its loader begin with the actual complete
native qualification registry. They require the genuine qualified 168-model
seal, the same exact pre-search procedure/plan/support and every retained budget
view. Caller-written success flags or a rehashed envelope cannot replace those
validations. All actual model/search snapshots are checked again before sealing.

The barrier fixes the P02–P13 V-selected champion separately for each dataset,
repetition and time-budget view. Both repetitions remain; P01 is the placement
counterpart and never enters that portfolio. A missing prefix family makes the
portfolio unavailable, rather than selecting a winner from an easier subset.
Energy remains part of the fixed inventory and retains its separate simulation
analysis scope.

Actual label-reading qualification/model audits run before the six primary-log
shared leases. The seal then records or revalidates the exact
[access prefixes](transfer-access-prefix.md), source, procedure and raw immutable
model/proof bytes without invoking label readers under those leases. Loading
allows only valid later primary events in the legacy log. Publication waits
until every validation context has completed its exit checks; a failed context
cannot leave the canonical barrier file published.

Successful actual execution would authorize **secondary development access
only**. It grants no T/protected-evaluation permission, secondary native-workload
qualification, whole-cost claim or confirmation result. Secondary shapes still
need their qualified execution route, and the later full post-secondary model
inventory/evaluator gates remain required. The returned object alone is no
permission token: a released-data API must reload and validate the real file.
Legacy `TransferStore` restrictions are unchanged.

The final affected six-module suite passed **90 checks in 10.35 seconds**.
Twelve initial missing-module failures preceded the first 89-check run. A
publication-boundary regression then failed before moving publication after
validation-context exits. The [receipt](WP09-practical-global-barrier-receipt.json)
retains all commands and source identities. Champion calculations use explicitly
untrusted toy rows; public negative tests reject false qualification before
reading protocol/model inputs or creating output.

**Actual complete-qualified public sealing/loading remains unrun.** No full
qualification or 168-model positive was fabricated. This is a source-tested
secondary barrier implementation, not an executed global freeze. Released
F/G/V and native-workload routes, protected evaluation/full artifact audit,
physical cost/CLI/readiness and final review remain unfinished before final-source
qualification and primary production.

The [secondary data API](released-transfer.md) now reloads this barrier and uses
its exact prepared-root map, with a separate protocol-bound access journal.
It still denies T and does not qualify secondary native workloads or searches.
