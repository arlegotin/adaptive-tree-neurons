# Native inspected trial bridge

`research.native_trial_bridge_v2.InspectedNativeTrialBridge` connects an exact
primary search proposal to uncapped managed fitting, independent closed-model
prediction replay and the logged primary V evaluator. This is an engineering
composition; it does not grant production quality eligibility.

The constructor binds the current source, native template, paired fit seed,
prepared primary split, original F/G/V-feature bytes and exact semantic family
support/anchor order. It creates no search directory. Generic TPE draws compile
through the existing strict family compiler; P13 follows its exhaustive29-model
support. P06 now requires the separately authenticated
[official native schedule](native-official-schedule-worker.md) and fixed native
HPO seed; its exact32configurations are bound and rechecked. Its native
distribution never becomes generic TPE. Missing or changed schedule evidence
rejects before fitting.

Each paid attempt creates a separate generation container with
[verified immutable archives](immutable-input-staging.md) and a recorded hard-link
or cross-device copy method. The owned fit has no wall deadline and retains its RSS guard. Successful
native completion is inspected in a fresh process, with V labels remaining in the
coordinator. A packet keeps the raw/compiled proposal, model lineage, inspected
V score, nested timings and complete file commitments. Outer search time includes
all those stages and publication; nested times cannot be added twice.

An owned memory stop or interruption retains a recovery packet and pauses the
search. Its one allowed recovery consumes another paid slot, preserves the exact
request/configuration/source/data/seed and writes a fresh attempt. NODE copies
its authenticated training checkpoint; other methods explicitly restart the same
seed. Old evidence remains unchanged. A second interrupted attempt is governed
by the existing terminal recovery limit. Global resource forecasting/admission
still belongs to the future production runner.

Inspected engineering models return `completed_ineligible` and no outer V score,
so they cannot win a search. The diagnostic V value is retained separately.
Native workload/support qualification, complete HPO evidence and final protocol
authority remain required before any production selection. This component does
not alter historical eligibility flags or access secondary/T labels.
