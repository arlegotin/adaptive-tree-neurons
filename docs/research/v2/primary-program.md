# Serial primary practical program

`run_primary_program` composes the actual qualified caller for the fixed 168
primary searches. It requires the program request subtype, exact procedure and
resource references. Actual complete native qualification comes before reading
the plan or creating outputs. It then checks the current semantic declaration,
measured forecast and output boundaries against working data, proof, interpreter
and other inputs. It admits no secondary fold or T access.

The immutable program plan preserves both repetitions, source/support/lock/data
identities, native budgets and job order. The separate pure builder binds
metadata without authenticating qualification or the forecast. Those references
cannot become permission through a caller-written flag.

An exclusive lease and hash-chained episode journal retain each job's exact
closed-body and never-authorized histories. Resume requires the externally
pinned journal SHA. Resource denial closes a paid pause on the same job, with
no fit slot or new seed. Native patience and the existing 32-attempt HPO/recovery
rules stay inside the worker; an administrative return bound does not shorten
a fit. Terminal searches advance in order. A search without an eligible winner
does not become a predictive loss or a qualified selected model.

Every terminal search receives the genuine native/HPO/V audit before advancing.
On a new invocation, saved terminal searches are audited again. Within that
invocation, journal/caller commitments are reopened without repeatedly running
the same expensive native audit for every later close. The strong 168-model
barrier remains required and revalidates all actual selected models; queue
progress is not that barrier.

If the driver stops after a caller closed but before its journal close, recovery
reopens the exact caller evidence and records it without starting another fit.
A started episode without complete caller evidence fails closed. Its unknown
tail is not zero, and an authorized failed/ambiguous body is not silently
replaced. Original evidence remains available for a named recovery.

Progress retains the sum of unique observed caller clocks. Separate invocation
receipts measure entry through qualification, queue activity and readback; their
own final publication/return remain excluded. These clocks are nested and must
not be summed as independent costs. Complete physical whole-cost authentication
and any efficiency claim remain separate requirements.

Initial verification had two missing-module failures and three setup errors.
The first queue checks passed five cases; two added interruption boundaries
passed existing behavior. A final run followed body-authority checks and removal
of redundant within-invocation native audits. The [receipt](WP08-primary-program-receipt.json)
retains commands and raw evidence. A read-only capture reopens two real no-child
program-request denials and their exact accumulated caller clocks. No registry,
forecast, role array or model was opened by that capture.
