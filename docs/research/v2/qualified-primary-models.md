# Exact primary-model barrier

The existing primary selection inventory binds all 168 primary jobs and their
chosen files, while granting no native or release authority. Its deliberately
narrow file check can accept another artifact from the winning attempt, such
as a log. The new `qualified_primary_models_v2` layer requires the precise
winning checkpoint metadata and every file in its snapshot instead.

Both seal and load begin with the actual complete native qualification registry.
For every primary job they call the genuine qualified search auditor, checking
all paid attempts, native outcomes, V scores and the terminal winner. The chosen
model must equal that auditor's exact metadata reference and full snapshot
inventory. Complete search inventories are pinned before each audit, checked
after it and checked again at the end, including losing evidence and unexpected
files. Source, qualification and the older primary inventory are rechecked.

The barrier also now requires the exact [pre-search practical procedure](practical-procedure.md),
after actual qualification and inventory validation, and rechecks its semantics
at the end. An arbitrary JSON procedure is insufficient. Successful execution
would establish the fact that all 168 primary models have the required qualified
search evidence and that pre-search declaration. It would still grant no post-search
global-procedure freeze, secondary label release, protected evaluation or complete cost
claim. Loading the resulting artifact repeats the genuine validations; a
self-rehashed payload or success flag cannot substitute for them.

The affected suite passed **74 checks in 34.08 seconds**. Byte-only fixtures
reject logs, a different snapshot, changed tensors, extra files, symlinks and
altered commitments. The public seal and loader reject false qualification
before touching a primary inventory or search. The older metadata-only fixture
inventory stays explicitly unqualified.

**Complete execution on 168 actual qualified searches remains unrun.** No full
registry success or completed cohort was fabricated for testing. The helper
observations authenticate paths and bytes only, with native/protected flags
false. The [receipt](WP08-qualified-primary-models-receipt.json) retains initial
failures, source, commands and fixture boundaries.

Measured production admission and launcher/cost reconciliation, the complete
global procedure protocol and protected evaluator remain unfinished. Current
engineering baselines are not promoted into this barrier by their completion
counts or by a passing software suite.
