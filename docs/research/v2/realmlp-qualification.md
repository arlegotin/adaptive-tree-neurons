## Recipe and protocol boundary

The official source, wheel, private dependency closure and original reviewed
contract are pinned in [the contract](realmlp-adapter-contract.md) and
[dependency record](realmlp-dependencies.md). The implementation invokes the
pinned native factory, initialization, custom optimizer/factors/decoupled WD,
embeddings/scaling/clipping and full declared schedule. Full native mode is
256 epochs; tiny mode explicitly changes it to at most3 and stays quality-
ineligible. The adapter fits the official category converter on F before G
transformation. Native target statistics already fit F; this is not an adapter
departure. Unknown code0 and native one-hot/embedding behavior are preserved.
No F-mean fallback or shortened native patience policy was added.

Pinned native validation is original-coordinate RMSE, although the paper
describes MSE. Training accepts its separate mse loss key. Log raw MSE and
native RMSE, preserving native latest-best<= checkpoint selection in float32.
A raw-G callback executes before native Metrics.apply can sanitize nonfinite
predictions, and rejects every observed nonfinite evaluation. F loss, gradients,
updated parameters and fitted state must be finite.

Native batch256/drop_last=True/adjust_bs=False are preserved. Every F row is
admitted to the loader; each epoch's omitted shuffled tail and cumulative
exposure are stored. The first3-epoch checks exposed299/300 numeric rows and
297/300 mixed rows. These omissions remain records, not a reason to change
seeds, loader treatment or epochs. Full256 exposure is not inferred from them.

## Representation and authentic reload

The root-approved [snapshot proposal](realmlp-snapshot-proposal.md) precedes
implementation. Two explicit native graphs (fitted model and static one-hot
preprocessing), Variable parameters/buffers, contexts/hyper_factors, constructor
flags and allowlisted functions are captured in strict JSON/NPZ. No class name
from JSON is imported or evaluated; no generic pickle/state_dict-only shortcut
is used. The official F vocabulary is reconstructed via a synthetic category
carrier with zero numeric fields, with exact native category code/order/size
checks. No original F/G features, labels or observations are retained to load a
model. Native static-before-batch execution and1024 batching are preserved.

A trusted external manifest digest is mandatory. Load checks source, all27core
plus15private package identities/RECORDs/selected import bytes and actual native
images, resolved factory config, mode, nonnegative finite risk history, latest-
best selection, complete epoch/update/row exposure, graph shape/activation/
NTP factors/category/embedding coherence and every tensor byte/dtype/shape.
Loaded models permit inference only; training, optimizer recovery and resaving
as a newly fitted state are rejected. Native training interruption recovery
and deployment qualification are explicit future work.
