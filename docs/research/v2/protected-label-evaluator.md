# Once-only frozen prediction scoring

The public evaluator requires the actual final practical protocol and complete
prediction-stage proof before reading study or label files. It validates the
same context again before labels and before committing results. Callers cannot
supply a context or an authorization flag. Complete-qualified public success
remains unrun.

The evaluator scores saved original-unit predictions. It never loads, fits or
predicts a model. All frozen model views remain visible, including unavailable
prefixes. Each query keeps its exact row/group/time identities. F target
variance uses ddof0; primary losses weight groups or actual days equally, then
rows within them. Row-weighted MSE/RMSE/MAE and per-group normalized losses are
also retained. Missing hours are preserved. Overlapping F/T rows, extra target
archive fields, changed bytes, nonfinite targets and identity mismatches fail.

A witnessed `labels_started` event precedes target access. Every role read has
an evaluator access-start record and a closed success/failure record. Source
identity is checked before each read. The metric artifact binds those records,
the complete query/view inventory, data roles and owner genesis. Its closed
completion reference also binds the observed evaluator clock; the journal
commits that completion only after validation.

Revisiting committed results validates saved evidence without reopening label
arrays. A fully published result and closed clock interrupted before journal
commit can be committed after revalidation without another label read. A stage
without complete closed evidence blocks automatic reset or re-evaluation.
Failed reads and their clocks remain available. Clock publication, journal
publication, return and containing caller costs still need their outer record;
this component grants no complete-pipeline cost or predictive claim.

scored against known fixture targets; its read-only replay opened no targets.
The other pair demonstrated changed-target rejection and blocked incomplete
retry, with the original target bytes retained. These are software fixtures,
not benchmark results or genuine protected test access.

Inferential comparisons must consume these frozen metric inputs with the
predeclared V champion and paired resampling. Independent raw/model/access
audit, deployment, full cost, report/CLI/readiness and final review remain
required before final-source qualification and production searches.
