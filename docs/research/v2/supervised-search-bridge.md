# Supervised engineering search bridge

Connect the immutable paid-attempt controller to the fresh method worker on
fixtures, without promoting engineering models or reading V labels. Constructor
bindings include the search plan, source, fixed fit seed, externally committed
F/G/query template, interpreter and optional pinned method overlays. Every trial
uses the exact requested configuration and the remaining enclosing budget.
Never substitute a model, drop an attempted failure, select a seed or change
the method's native procedure.

Materialize byte-authenticated role archives inside each attempt input directory.
Use hard links for these immutable generated arrays when the filesystem permits,
with a verified byte-copy fallback for cross-device inputs. Both choices and all
logical sizes are recorded. Workers load copied arrays and never write the role
archives. Recheck the shared source files and staged files after execution. Any
change fails the attempt and stops for diagnosis; it does not authorize replacing
the input. This avoids retaining a new physical data copy for every trial while
keeping each trial's complete readable evidence. It does not save or conceal
model fitting, native preprocessing, search or parent-training cost.

Include staging, hashing, process startup, fit, query prediction, closed snapshot,
failure handling and coordinator work in the paid callback. Subtract preparation
from the remaining deadline before invoking the own-process supervisor. Retain
all process/worker artifacts and externally timed supervisor receipt publication.
The outer controller also authenticates partial files if a callback unexpectedly
fails, then stops for diagnosis. Source/data/environment changes cannot resume an
old trial identity. Ordinary clean pauses resume the exact committed queue.

The engineering worker always returns ineligible results. This bridge returns
no V score, never opens V labels and grants no protected access. Full native
quality/registry admission, actual V-scoring integration, native checkpoint or
same-seed infrastructure recovery, whole-process search crash recovery and final
resource qualification remain separate requirements before production HPO.

Acceptance uses actual tiny P13 worker processes, one retained deliberately
unsupported configuration, paid slots, a clean pause/resume, original seeds,
all-file commitments and a no-winner result. These fixtures do not execute the
840-job practical benchmark or qualify any native quality comparison.

## Typed generic TPE proposal contract

The implemented Task8 slice adds `CompiledEngineeringTrialBridge` in
`research/compiled_trial_bridge_v2.py`. It requires the exact family descriptor
hash, atomic support and native anchor sequence from `search_supports_v2`.
P06's native sampler and P13's finite support retain their existing direct-config
path; this wrapper cannot replace either with generic TPE. The per-search support
identity names the canonical family descriptor; the eventual global lock must
bind every family descriptor separately from its enclosing file digest.

The wrapper translates only declared raw TPE proposals, preserves exact native
anchors, and calls the existing owned-process engineering bridge. Compilation
and provenance preparation consume the same remaining enclosing trial budget;
there is no added trial or free prefix work. The original controller proposal
remains unchanged. Each attempt retains raw/compiled configurations, source and
support commitments, inactive conditional coordinates and translation timing.
The final artifact inventory includes the translation file. Clean pause/resume
uses the same immutable plan, fitting seed and sampler journal.

This remains an engineering-only connection. No V labels/scores, winner,
production admission, native quality promotion or protected access is supplied.
A later separately qualified coordinator must independently authenticate V
predictions and compute the declared group/day metric before production search.
