# Retained models for native quality and time-budget views

The native-quality winner and the 10/30/120-minute prefix winners can be different
models. `inspect_budget_model_views` binds each view to the precise snapshot
available at that endpoint, using the existing completion-time, V-score and tie
rules. A later better model cannot replace an earlier budget winner. A prefix
with no eligible completed model stays unavailable; it is not scored as a loss.

The helper requires every supplied eligible candidate's metadata and complete
snapshot inventory. Changing tensors, substituting a log, omitting an eligible
model or altering a prefix table fails. Multiple views can reference the same
snapshot. This helper checks supplied arithmetic and bytes only; it grants no
native/model-generation or protected authority.

The genuine qualified search auditor now collects those model bindings from
every actually eligible native generation after its existing registry, paid
attempt, HPO and V checks. The strong primary-model barrier retains all four
views per job, verifies the native view equals its existing winner, and rechecks
every distinct retained snapshot before publication. Complete search evidence
and all 168 actual primary audits are still required.

The affected four-module suite passed **74 checks in 8.18 seconds**. Ten initial
missing-interface failures were retained. An expanded sandbox run passed 62 and
failed 12 because owned native failure/recovery fixtures could not invoke
`/bin/ps` before worker startup. The unchanged source passed with that owned PID
inspection permitted. The [receipt](WP09-primary-budget-models-receipt.json)
retains both runs. Toy byte snapshots verify different prefix winners, late
unavailability and stable ties; their scores/times are not benchmark results.

Actual complete-qualified search and 168-model positive execution remain unrun;
no full registry success was fabricated. This completes a prerequisite for the
post-search [primary global barrier](practical-global-barrier.md), whose actual
qualified execution remains unrun. This byte helper grants no secondary or T release and
does not change native stopping or impose a two-hour training limit.
