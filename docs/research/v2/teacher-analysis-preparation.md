# Prospective teacher inference preparation

Pure v2 analysis now consumes the complete declared teacher/repetition/role risk
inventory. It averages exactly two risks per teacher/role before taking the log
ratio. The independent count remains the number of teachers. Every exact no-op
teacher remains included. Missing or failed planned cells prevent primary
inference; invalid, duplicate or undeclared records fail validation. Zero mean
risk leaves that logarithm undefined without an epsilon replacement.

The primary output is the two-sided95% Student-t interval and the one-sided
p value at log(1/.98). The whole-teacher percentile bootstrap is a separately
labeled sensitivity output, with20,000default resamples, identical chunk-independent
index draws, index commitments and all bootstrap means retained. All teacher
effects, signs, median, range and5th/95th percentiles remain visible. Constant
teacher effects have undefined t variance and cannot obtain a t-based win from
an invented standard error. These functions grant no protected access, authenticate
no raw predictions and authorize no claim. A valid32–128 grid count alone is not
a frozen protocol or validated inference design.

Holm adjustment requires every hypothesis in the explicit declared family. Missing,
nonfinite or extra p values cannot reduce multiplicity. Adjusted values are
monotone in the ordered tests, with stable declared ordering for ties. Strict
rejection at .025 preserves the strict useful-margin convention. These adjusted
p values are not presented as simultaneous confidence bounds; compatible-bound
and complete frozen-report integration remain pending.
