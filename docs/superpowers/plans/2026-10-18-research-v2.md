# Research v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute the finite continuation, testing placement, capacity and practical quality–cost claims with durable evidence and honest gate outcomes.

**Architecture:** Preserve legacy scientific interfaces and add a versioned research layer. Immutable attempt lists, role-safe workers, source-bound checkpoints and append-only cost/status records feed an exact selector and independently reconstructed reports. **Spec:** `docs/superpowers/specs/2026-10-18-research-v2-design.md` (binding scientific contract).
