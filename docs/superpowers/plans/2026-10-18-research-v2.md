# Research v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Execute the finite continuation, testing placement, capacity and practical quality–cost claims with durable evidence and honest gate outcomes.

**Architecture:** Preserve legacy scientific interfaces and add a versioned research layer. Immutable attempt lists, role-safe workers, source-bound checkpoints and append-only cost/status records feed an exact selector and independently reconstructed reports. Conditional scientific tasks execute only after their recorded gates; production evaluation code precedes the source freeze.

**Spec:** `docs/superpowers/specs/2026-10-18-research-v2-design.md` (binding scientific contract).

## Review Focus

- Malformed current or embedded-best state must fail before publishing a new pointer, without silently casting tensors.
- Zero-gradient, rank-deficient and full-row-span cases must remain visible with correct count/ties and no false span claim.
- Interrupted queues and G-best restoration must preserve model state while retaining losing attempts and consumed costs.
- Small-group and temporal splits must obey minima/24-clock-hour embargo and primary-only development barriers.
- Missing native anchors or predictions must block the corresponding claim and never become adverse predictive scores.
