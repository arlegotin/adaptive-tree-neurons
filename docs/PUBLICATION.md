# Public release scope

## Project sunset, 21 October 2026

The owner ended the project and requested removal of local artifacts, worktrees
and project-specific caches. The main source checkout and the public Git history,
reports, compact results and selected audit evidence are retained. Local raw
experiment archives, checkpoints, environments and auxiliary worktrees have been
removed. No new scientific run, protected evaluation or upgraded result follows
from this cleanup. The incomplete practical benchmark remains incomplete.

Historical publication receipts and inventories describe their original checks
and retention state. They are preserved, while current documentation records
that the project-local raw bytes are no longer available. Full raw authentication
cannot be performed from hashes and compact tables alone. The
[cleanup record](../provenance/sunset/2026-10-21/README.md) identifies the scope.

third-party terms retained in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

version 0.1.0 and its original release date; no new version or DOI is invented.

Historical machine paths and selected small engineering fixtures remain public

## Original release, 18 October 2026

This release starts from research handoff `7af00e8`. It prepares the presentation,
licensing, citation and package metadata for public use. It does not rerun the
scientific cohort, change the allocation score or architecture, rebind historical
receipts, or strengthen the predictive claim.

## Included and external material

The public repository includes source, tests, configurations, the core lock,
original reports, decisions, prior-art notes and selected detailed audit records.
Full Git history is retained so recorded source commits remain meaningful.
Selected historical logs under `environment/` are versioned too; they are not
the installed runtime or the full retained experiment archive.

Small synthetic engineering arrays and saved numerical states are already
versioned in `tests/fixtures/` and selected historical audit directories. They
support numerical regression and backend diagnosis. They are distinct from the
full scientific training archive and pretrained third-party weights. Inspect
their recorded provenance before using them as anything beyond fixtures.

Full pilot/cohort observations, predictions, training events, final checkpoints,
installed environments, caches and the downloaded publication scanner remain
outside Git. Public inventories identify retained external bytes, not downloadable
copies of them. Complete raw-result authentication requires those assets.

Historical metadata includes the owner's name, public Git author email, local
filesystem paths, OS/runtime information and permitted coarse machine-resource
observations. Old machine paths are preserved as evidence; they are not portable
configuration. No private archive was moved into Git for this release.

## Supported claims

The layer implements selected affine-stump growth with preserved initial
predictions, a nonzero hidden contrast and an initially learnable gate. The
reported score, control pipeline and state-recovery checks are implemented.
The latest independent saved-prediction arithmetic and representative same-source
replays agree exactly. These are internal reproducibility checks, not an
independent laboratory replication.

The earlier 16-problem pilot and fresh 8-problem diagnostic remain exploratory.
Neither establishes a clear benefit of the cheap selector over matched random
placement. Longer validation search adds cost without establishing a clear
placement advantage. A comparison against a fresh ordinary network does not
establish superiority over warm ordinary widening or a tuned practical baseline.
No protected confirmation, general tabular superiority, novel model family or
hard-routing acceleration is claimed.

## Publication verification

Verification records are stored under `provenance/publication/2026-10-18/`.
The tested clean clone was at preparation commit `a7e692c`, with imports verified
to come from its own `src/` tree. It reused the existing locked Python/dependency
environment; the original scientific archive was absent. This was an artifact-free
source check, not a fresh dependency installation on a second machine.

- The README example, both standalone math/gradient references and CLI help pass.
  The focused clone command passed **89 tests, with 1 MPS skip**, in 11.14s.
- A first complete suite attempt with core-only dependencies and default Torch
  interop settings produced **928 passes, 48 skips and 74 failures** in 1920.73s.
  The failures comprise 49 receipt/thread-setting mismatches, 18 missing-Optuna
  cases, 6 missing NODE-reference dependency cases and 1 dependent causal-CLI case.
  That run is retained; it is not presented as green.
- Installing the existing hash-pinned NODE/reference and search overlays into
  the disposable clone and explicitly initializing both Torch thread counts to1
  resolved every one of those 74 failures. Their exact nodes plus algebra,
  growth, score, diagnostic, training and checkpoint regressions passed
  **228 tests, with 1 skip**, in 82.27s. The corrected full setup is documented in
  [REPRODUCE.md](../REPRODUCE.md#full-test-setup). No test, scientific source,
  configuration or core lock was changed to obtain this result. There was no
  second monolithic full-suite run; these are distinct measured checks.
- Independent release review verified the claims, figures, API, attribution and
  privacy boundaries. Its one package-metadata correction, naming MIT alongside
  AGPL/CC BY for bundled vendor code, was checked before and after correction and
  verified in the rebuilt distribution. All eight legal/notice documents remain.
- Gitleaks8.30.1 initially flagged71 strings in76 reachable commits. Each was
  inspected in its actual historical blob: all were research SHA-256 identities,
  68 independently recomputed and3 identified from retained-ledger inventory
  context. The exact59 immutable historical fingerprints are dispositioned;
  new commits, paths, values and other rules remain scanned. The subsequent
  history scan reported0 new findings. This bounded review found no credential
  blocker; it is not a guarantee about every possible secret encoding.

The full initial output, configured regression output, invocation records,

Final presentation/licensing changes do not alter the tested scientific source.
